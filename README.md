# CodeOrbit - Personal Portfolio Website

A responsive personal portfolio website showcasing my technical skills, projects, and contact information as an aspiring full-stack developer.

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, dark theme, layouts, and responsive design
- **JavaScript** – Mobile navigation and dynamic footer year

## Features

- Responsive design for desktop, tablet, and mobile devices
- About Me section introducing my background and career goals
- Technical Skills section
- Projects section with GitHub repository links
- Contact section with email, GitHub, and LinkedIn links
- Mobile-friendly navigation menu
- Dark theme with blue accents
- No frameworks required

## Projects Featured

- Student Management System
- Login System
- User Authentication System
- REST API
- To-Do List Application
- E-Commerce Backend

## Setup Instructions

1. Clone this repository:

   ```bash
   git clone https://github.com/mohamud007/CodeOrbit_My-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd CodeOrbit_My-Portfolio
   ```

3. Open `index.html` in your web browser.

4. Alternatively, open the folder in Visual Studio Code and use the Live Server extension to preview the website.

5. To personalize the website, update the profile photo in the `images` folder and edit the email, social media links, and project details in `index.html`.
